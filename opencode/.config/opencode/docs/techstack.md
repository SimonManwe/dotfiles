# Tech Stack

## Professional (Company)

- **Backend:** PHP / Spryker Commerce OS
  - Spryker Docker SDK for local development
- **Frontend:** TypeScript, JavaScript, React
- **Source control:** GitLab
- **Infrastructure:** Docker-based development environment
- **OS:** Linux Mint / Ubuntu

## Personal Projects

- **Systems/Backend:** Rust
  - **Philosophy:** Std-first, minimal crate dependencies
  - Acceptable exceptions: `serde` (serialization is fundamental), `tokio` (when async is truly needed)
  - Always check if `std` provides it before reaching for a crate
  - Prefer implementing things from scratch as a learning exercise
- **Web/Frontend:** TypeScript, React, Next.js
  - Local dev: native (no Docker), optional docker-compose available
- **Source control:** GitHub
- **OS:** Arch Linux

## Development Environment

- **Editor:** Neovim (custom config, built from scratch with plugin manager)
- **Terminal:** Ghostty + tmux
- **Shell:** zsh (customized)
- **CLI tools:** ripgrep (`rg`), fd, bat, lazygit
- **Philosophy:** Terminal-centric workflow — prefer TUI/CLI solutions over GUI when possible

## Package Managers

- **System (Arch):** pacman / yay (AUR)
- **System (Ubuntu/Mint):** apt
- **Node.js:** No strong preference (npm/pnpm/yarn — depends on project)
- **Rust:** cargo
- **PHP:** composer
